# A Journey of Faith through Israel

A 19-minute, 12-second Full HD video, made with the supplied footage, KJV Scripture, and gentle music. Two source clips over 100 MB could not be downloaded and are not included. The supplied footage is Israel-themed, but the precise location of every shot has not been independently verified; check locations before identifying individual scenes.

## Download as one MP4

Download `Download_Journey.html` using GitHub's **Download raw file** button. Open that downloaded file in Chrome or Edge and click **Download the video**. It downloads and verifies each part, then saves one `Journey_Through_Israel.mp4`. Keep the page open until it finishes. The download is about 929 MB; you need at least that much free space. On phones or browsers without a save picker, the browser may require enough memory to assemble the video.

Alternatively, download `download_journey.py` and run `python download_journey.py`. It saves a single verified MP4 in the folder where you run it. Python 3 is required.
